研究假设

创新组合

事件先过来源、时序、重放和父证据校验；本地快速路径负责立即放行或强制；只有已验证且需要语义解释的事件才进入 Jev。Jev 输出被绑定为有期限软证据，与哈希链账本和会话滞回关联。

可验证指标

远程调用减少率、P50/P95 延迟、重复事件复用率、未验证事件外发数（目标为 0）、父证据失效后的阻断率、SAFE_STOP 保持率。在线模型准确率需另做带标注数据集实验。

专利边界

可围绕“安全事件验证—本地分流—会话级语义证据—父证据生命周期—安全状态机”的组合方法撰写交底；开源项目对比只是先前技术线索，不能代替新颖性检索和法律意见。
