```bash

```

GitHub标签和本地ZIP提供源码快照。语料库的大型二进制文件沿用Git LFS；源码ZIP中的这些文件可能是LFS指针，完整语料请按上方克隆并拉取。保留第三方语料中的许可证和来源记录。

源码包不包含构建目录、研究虚拟环境、运行日志、临时控制Key、浏览器状态或聊天记录。历史实验的完整原始产物在本机忽略的 `experiments/results/` 中，未随源码快照分发；前端公开样例和实验快照随源码保留，可使用对应实验脚本重新生成原始产物。

## 构建与离线验证

在Ubuntu 22.04 / WSL中准备ROS 2 Humble后运行：

```bash
bash deploy/run_guardian.sh build --distro humble
source /opt/ros/humble/setup.bash
source install/humble/setup.bash
python3 -m venv --system-site-packages output/agent-review-venv
output/agent-review-venv/bin/python -m pip install \
  -r experiments/requirements-agent-review.txt \
  -r experiments/requirements-fuzzing.txt
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 output/agent-review-venv/bin/python -m pytest -q tests

# 不调用真实模型；输出文件必须不存在。
output/agent-review-venv/bin/python experiments/run_agent_review.py \
  --sample --output output/snapshot-agent-review.json
```

部署需要另行生成控制签名Key和管理员密码，使用 `deploy/guardian.env.example`。仓库 `.env` 仅保留无凭据的默认配置，不能填入真实Key后提交。
