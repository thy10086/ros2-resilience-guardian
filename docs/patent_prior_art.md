# 专利化方向的开源参考与差异边界

查询日期：2026-09-23。下列项目用于理解工程先例，不构成完整专利检索，也不代表不存在其他公开文献。

| 参考项目 | 可借鉴内容 | 当前方案的差异边界 |
| --- | --- | --- |
| [ROS 2 SROS 2](https://github.com/ros2/sros2) | DDS-Security 密钥、证书和权限工具 | SROS 2 解决身份和权限配置；当前新增运行时图因果路径、证据链、预测包络和恢复凭据绑定 |
| [Navigation2](https://github.com/ros-navigation/navigation2) | ROS 2 导航框架及控制器生命周期 | 当前方案位于导航控制器外部的安全决策边界，输出速度/停车约束，不替代导航规划 |
| [Nav2 Collision Monitor](https://github.com/ros-navigation/navigation2/tree/main/nav2_collision_monitor) | 依据传感器区域和碰撞距离限制速度或停车 | 当前方案额外计算控制/传感器延迟、风险增长和证据严重度，并把安全状态绑定到恢复上下文 |
| [RTAMT](https://github.com/nickovic/rtamt) | 在线/离线 STL 运行时监控与鲁棒度 | 当前方案不复制通用 STL 引擎；将策略版本、图指纹、账本锚点用于 ROS 2 恢复凭据和安全包络 |
| 现有 ROS 2 IDS 参考 | 话题、来源和异常检测 | 当前方案关注检测结果如何经过证据链影响速度、停车和可验证恢复 |

## 本仓库已有公开能力

早期版本已经公开事件验证、风险引擎、图传播、融合、驾驶舱和可选 Jev 顾问。这些能力不能作为本轮新增方案的单独新颖性依据。本轮交底应集中于以下组合及其交互：

1. 风险传播路径与拓扑指纹进入证据链；
2. 证据账本锚点与预测制动包络联动；
3. 风险增长和控制延迟共同决定速度上限；
4. 图、策略、账本、命令代次共同约束一次性恢复凭据；
5. 反事实解释只读地验证触发原因，不改变实时安全状态。

正式申请前仍需检索 CNIPA、Google Patents、WIPO Patentscope 及机器人安全相关论文/标准，并由专利代理师确认权利要求的技术特征组合和公开风险。
