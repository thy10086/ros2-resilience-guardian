# 专利化创新实验报告

日期：2026-09-23。运行命令：

    python3 experiments/run_patent_innovation_experiments.py

脚本是离线确定性实验，不调用 Jev、ROS 2 网络或真实底盘。

## 实验结果

### 1. 因果路径与图变更

nav → cmd_vel → base 风险为 0.9 × 0.8 × 0.9 = 0.648，输出完整路径和关键执行器。把 nav→cmd_vel 权重从 0.8 改为 0.5 时，图变更记录为 nav->cmd_vel；超过新鲜度窗口的图快照被拒绝。

### 2. 证据完整性与篡改

两条证据形成父子链并生成记录数为 2 的锚点。原始链验证通过；修改第二条记录的严重度后，哈希链验证失败。实验只证明检测到当前进程可见的记录修改，不等同于带密钥的数字签名或远程不可抵赖存储。

### 3. 预测包络与固定阈值对照

| 策略 | 速度上限 | 状态 |
| --- | ---: | --- |
| 现有固定风险包络，风险 0.1 | 0.315 m/s | CONTAINING |
| 预测包络，风险不增长 | 0.315 m/s | NORMAL |
| 预测包络，风险增长率 0.8/s | 0.175 m/s | CONTAINING |

预测风险为 0.5，停车距离为 0.38 m，比固定阈值提前降低速度。该结果只说明给定一维模型和输入下的单调性，不代表实机制动性能。

### 4. 双阶段恢复对照

现有布尔恢复门控在一次全真快照下允许恢复。新协议需要 RECOVERY_PROBING、稳定窗口后的 RECOVERY_CANDIDATE、驻留时间和一次性上下文绑定凭据；凭据重放或图指纹变化都输出 SAFE_STOP。

### 5. 证据保障和反事实解释

物理硬停车证据使等级为 SAFE_STOP。移除该证据重算为 CONTAIN，说明解释能识别停车的必要证据；移除操作不改变账本或实时状态。

## 研究指标与后续

当前脚本验证确定性行为：路径可追溯、篡改可检测、速度随风险增长下降、恢复凭据不可重放。后续接入 ROS 2/Webots 后，应测量检测延迟、停车提前量、任务完成率、误报率、CPU 开销、图刷新开销和恢复失败率，并与 SROS 2 权限、Nav2 Collision Monitor、原有固定阈值策略分别比较。
