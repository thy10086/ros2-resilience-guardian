# 软件专利技术交底书草案：面向 ROS 2 机器人的可溯源预测安全防护与恢复方法

版本：0.1（工程交底草案，2026-09-23）

## 一、发明名称

一种基于运行时因果风险图、证据溯源账本、延迟补偿安全包络和上下文绑定恢复协议的 ROS 2 机器人韧性防护方法、系统、设备及存储介质。

## 二、技术领域

本方案属于机器人操作系统安全、网络物理系统安全、运行时验证和安全控制领域，具体用于 ROS 2 节点、话题、传感器、导航控制器和执行器组成的数据路径。

## 三、要解决的技术问题

现有 ROS 2 入侵检测或安全停车方案通常分别处理 DDS 身份、消息时序、碰撞距离或攻击告警，存在四个断点：

1. 告警不能说明风险经哪条 ROS 2 数据路径到达执行器；
2. 多种证据合并后缺乏可复核的来源、版本和时间关系；
3. 固定阈值没有补偿感知和控制延迟，可能在风险增长时降速过晚；
4. 停车解除常由一次性健康判断触发，旧命令、旧拓扑或短暂恢复可能重新获得运动权限。

## 四、技术方案

系统由以下安全模块构成：

1. **运行时因果风险图模块**：把 ROS 2 节点、话题、传感器和执行器建模为带信任域、关键度、关系出处和传播权重的有向图，生成不含采样时间的拓扑指纹；以已验证风险为种子沿最大乘积路径传播，输出执行器风险、路径和跨信任域记录；比较相邻快照并使图变化立即成为新证据。
2. **证据溯源账本模块**：将身份、时序、物理、图传播和语义结果写成不可变证据记录。记录包含来源、类型、节点、观察时间、失效时间、置信度、严重度、策略版本、父证据、替代关系、验证标记和硬停车标记。每条记录与前一条记录计算哈希链；输出“记录数、链头”锚点，验证篡改或截断。
3. **延迟补偿预测安全包络模块**：根据当前速度、可用距离、制动加速度、控制延迟、传感器延迟、预测时域、测量不确定度和预测风险增长计算安全速度。其一维实现采用：

   d_stop = v × tau + v² / (2a) + d_margin + d_uncertainty + d_risk

   其中 tau 为控制和传感器延迟之和，d_risk 由预测时域内的风险增长得到。速度上限同时受制动距离不等式和预测风险上限约束；传感器过期、非有限输入、距离不足或预测风险超过停车阈值时强制 SAFE_STOP。
4. **证据保障与反事实解释模块**：使用有效证据的置信度—严重度组合生成 ALLOW、CONTAIN 或 SAFE_STOP；硬停车证据独立于平均分数。逐个移除证据并重算得到“没有该证据时的等级”，生成决策解释，但不修改实时账本。
5. **上下文绑定双阶段恢复模块**：状态按 SAFE_STOP → RECOVERY_PROBING → RECOVERY_CANDIDATE → RESUMABLE 变化。恢复观察必须连续满足无活动攻击、拓扑稳定、策略有效、传感器新鲜、旧命令清空、探测成功和风险边界；提交时生成有期限的一次性凭据，凭据绑定图指纹、策略指纹、账本锚点和命令代次。上下文变化、时间回退、凭据重放或到期会使状态回到 SAFE_STOP。

## 五、方法流程

1. 采集 ROS 2 图快照、已验证事件和运动状态；
2. 验证图快照新鲜度、节点/边完整性和输入数值范围；
3. 将事件作为风险种子沿因果图传播，记录关键执行器的路径和风险；
4. 将图、时序、身份、物理和可选语义结果写入证据账本并生成链头；
5. 计算当前和预测风险，结合延迟和制动模型求安全速度；
6. 根据硬停车标记、融合分数和安全包络输出安全状态；
7. 停车后进入探测阶段，连续观察形成候选恢复状态；
8. 用当前图指纹、策略版本、账本锚点和命令代次生成恢复凭据；
9. 在凭据有效且上下文未变化时仅授权一次恢复命令，否则保持安全停车；
10. 将每次状态变化、证据链头和解释写入审计记录。

## 六、有益效果

- 给出从攻击来源到执行器的可复核风险路径，减少只显示单一分数造成的定位困难；
- 用证据哈希链和策略版本绑定检测篡改、旧证据和跨来源替代；
- 将控制/感知延迟和风险增长纳入速度边界，使降速早于固定风险阈值；
- 使用一次性上下文凭据避免旧拓扑、旧命令或短暂健康窗口直接解除停车；
- 反事实解释保留工程审计能力，同时不让解释模块改变安全决策；
- 纯 Python 核心不依赖外部 AI 或网络服务，适合在单台笔记本和 ROS 2 Jazzy 上复现。

## 七、具体实施例

在 nav → /cmd_vel → base 图中，以 nav 风险 0.9 为种子，边权分别为 0.8 和 0.9，base 风险为 0.648，路径完整保留。当前速度 0.2 m/s、可用距离 2.0 m、控制延迟 0.2 s、传感器延迟 0.1 s 时，风险增长率 0.8/s、预测时域 0.5 s 将预测风险提高到 0.5，速度上限从固定阈值基线 0.315 m/s 降为 0.175 m/s。若硬停车传感器证据存在，即使平均分数低于停车阈值仍输出 SAFE_STOP。恢复凭据首次成功授权后立即失效，图指纹变化或再次使用凭据均拒绝恢复。

## 八、可保护的权利要求方向草案

1. 一种 ROS 2 机器人安全防护方法，其特征在于：构建带信任域和关系出处的运行时因果图，以经过验证的事件作为风险种子沿图传播，并将风险路径、图指纹和关键执行器风险写入证据记录。
2. 根据权利要求 1 所述的方法，其特征在于：证据记录按照父证据、策略版本和哈希链组织，并通过记录数和链头锚点验证证据完整性。
3. 根据权利要求 1 所述的方法，其特征在于：根据速度、制动加速度、控制延迟、传感器延迟、不确定度和预测风险增长计算安全速度上限。
4. 根据权利要求 3 所述的方法，其特征在于：预测风险超过停车阈值、传感器数据过期或输入非有限时输出安全停车。
5. 根据权利要求 1 所述的方法，其特征在于：对每条有效证据执行移除后重算并输出反事实等级，所述重算不改变实时安全状态。
6. 根据权利要求 1 所述的方法，其特征在于：恢复过程包括探测阶段和候选阶段，并使用绑定图指纹、策略指纹、证据锚点和命令代次的一次性有期限凭据授权恢复。
7. 一种实现上述方法的 ROS 2 安全防护系统、电子设备或计算机可读存储介质。
